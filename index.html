DE LA DESCARGA AL NAVEGADOR

Instala en tres pasos.

Ejecuta los comandos en el servidor Ubuntu 22.04.5. Utiliza un directorio de instalación nuevo y un puerto libre; aquí usamos el 19676.

1

Descarga y comprueba el paquete

Crea una carpeta de trabajo. El checksum debe devolver OK antes de continuar.

TERMINAL · DESCARGA
mkdir -p datagenomics-0.2.3
cd datagenomics-0.2.3
curl -fL -O https://github.com/datagenomicschatgpt/DataGenomics-Evaluation/releases/download/v0.2.3-evaluation/DataGenomics-Evaluation-0.2.3-ubuntu22.04-x86_64.tar.gz
curl -fL -O https://github.com/datagenomicschatgpt/DataGenomics-Evaluation/releases/download/v0.2.3-evaluation/SHA256SUMS
sha256sum -c SHA256SUMS
2

Descomprime e instala

La aplicación, los datos y los logs se mantienen en directorios separados. La instalación de la aplicación no requiere sudo.

TERMINAL · INSTALACIÓN NUEVA
tar -xzf DataGenomics-Evaluation-0.2.3-ubuntu22.04-x86_64.tar.gz
./DataGenomics-Evaluation-0.2.3-ubuntu22.04-x86_64/install.sh \
  --prefix "$HOME/DataGenomics" --port 19676
3

Arranca y abre la herramienta

Abre en el navegador la URL completa que devuelve dg url. Incluye la autenticación de tu instalación: consérvala en privado.

TERMINAL · LANZAMIENTO
"$HOME/DataGenomics/bin/dg" start
"$HOME/DataGenomics/bin/dg" status
"$HOME/DataGenomics/bin/dg" url

ANTES DE EMPEZAR

Preguntas frecuentes

¿Puedo descargar el tar sin acceso a repositorios privados?

Sí. El botón descarga el archivo directamente desde una GitHub Release pública. La aplicación y el acceso a componentes privados tienen permisos independientes.

¿Incluye pacientes, bases científicas o un caso precargado?

No. Una instalación nueva empieza sin casos. Los resultados autorizados y los recursos se incorporan desde tu entorno mediante sus contratos y controles correspondientes.

¿Tengo que instalar Python en cada ordenador?

Los analistas utilizan el navegador. La aplicación del servidor se distribuye con PyInstaller. Las etapas científicas necesitan su runtime y herramientas externos, configurados por el responsable.

¿Cómo entro desde otro ordenador?

La aplicación escucha por defecto en 127.0.0.1. Puedes usar un túnel SSH autorizado; para una instalación corporativa, el responsable debe configurar HTTPS, autenticación y acceso por LAN/VPN. El instalador no cambia la configuración de red.

¿Esta versión está preparada para emitir resultados clínicos?

Es una Evaluation Release. La instalación y el recorrido técnico tienen evidencias separadas de la admisión científica. La conexión operativa del piloto real sigue pendiente; consulta el alcance antes de procesar un caso.
