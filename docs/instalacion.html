Instalación y lanzamiento

Destino: Ubuntu 22.04.5 LTS x86_64. La aplicación se distribuye con PyInstaller onedir y se instala en un directorio de usuario, sin instalación global de Python.

1. Descargar y comprobar

mkdir -p datagenomics-0.2.3
cd datagenomics-0.2.3
curl -fL -O https://github.com/datagenomicschatgpt/DataGenomics-Evaluation/releases/download/v0.2.3-evaluation/DataGenomics-Evaluation-0.2.3-ubuntu22.04-x86_64.tar.gz
curl -fL -O https://github.com/datagenomicschatgpt/DataGenomics-Evaluation/releases/download/v0.2.3-evaluation/SHA256SUMS
sha256sum -c SHA256SUMS

La salida debe indicar OK. Si el checksum no coincide, no continúes.

2. Instalar en un directorio nuevo

tar -xzf DataGenomics-Evaluation-0.2.3-ubuntu22.04-x86_64.tar.gz
./DataGenomics-Evaluation-0.2.3-ubuntu22.04-x86_64/install.sh \
  --prefix "$HOME/DataGenomics" --port 19676

3. Arrancar, consultar y abrir

"$HOME/DataGenomics/bin/dg" start
"$HOME/DataGenomics/bin/dg" status
"$HOME/DataGenomics/bin/dg" url

Abre la URL completa en el navegador. La URL de entrada contiene la autenticación local: no la publiques ni la añadas a capturas o incidencias.

Acceso desde otro ordenador

La escucha por defecto es 127.0.0.1. Con acceso SSH autorizado al servidor puedes crear este túnel desde tu equipo:

ssh -L 19676:127.0.0.1:19676 USUARIO@SERVIDOR

Obtén la URL con dg url en el servidor y ábrela en tu navegador mientras el túnel esté activo. El despliegue corporativo por LAN/VPN requiere HTTPS y control de acceso configurados por su responsable. El instalador no cambia la red.

Parada y backup

"$HOME/DataGenomics/bin/dg" stop
"$HOME/DataGenomics/bin/dg" backup
"$HOME/DataGenomics/bin/dg" start

El backup exige servicio detenido y trabajos reconciliados. Los datos se conservan fuera del ejecutable. No borres SQLite o intermedios para eludir una guarda.

Actualización y recuperación

"$HOME/DataGenomics/bin/dg" update --package /ruta/absoluta/al/paquete
"$HOME/DataGenomics/bin/dg" rollback

La actualización conserva los datos; rollback vuelve al binario anterior. Consulta BACKUP_ROLLBACK.md del paquete para restaurar una copia. No sobrescribas una instalación existente con los comandos de instalación nueva.

Recursos científicos

La configuración privada está en config/local.json. Pipeline, Nextflow 25.04.8, Java 21, runtime científico Python 3.11.18 y recursos Dataomics son externos y requieren sus propios contratos y permisos. El servidor debe habilitar un perfil admitido; descargar e instalar la aplicación no habilita análisis clínicos automáticamente.

Una instalación nueva empieza sin casos. No se distribuyen pacientes ni bases científicas. La aceptación visual y la admisión de un caso real se realizan en la instalación autorizada.
